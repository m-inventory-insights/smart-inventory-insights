# مرصد المخزون الذكي — مشروع تحليل المبيعات والمخزون

موقع عربي تفاعلي (RTL) يحلل بيانات المنتجات والمبيعات والمخزون من ملفات Excel/CSV. لا يستخدم خادمًا خلفيًا؛ تتم قراءة الملف والحسابات داخل المتصفح.

## ملفات المشروع

- `index.html` — الموقع كاملًا مع التنسيق والتفاعل والرسوم البيانية.
- `قالب_بيانات_المخزون.xlsx` — ملف تجريبي به 50 منتجًا في ورقة «المنتجات» ودليل استخدام في ورقة «إرشادات».

## التشغيل محليًا

افتح `index.html` بمتصفح حديث واتصال بالإنترنت حتى يتم تحميل مكتبات SheetJS وChart.js والخط من CDN. يمكن تجربة المشروع مباشرة من البيانات التجريبية، أو رفع ملف Excel من زر «اختيار ملف Excel».

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديدًا باسم مثل `smart-inventory-insights`.
2. ارفع `index.html` و`قالب_بيانات_المخزون.xlsx` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. بعد انتهاء النشر سيظهر رابط الموقع في صفحة Pages. افتح الرابط وجرب رفع ملف Excel.

## عناوين الأعمدة المطلوبة

يجب أن يحتوي الجدول على: «اسم المنتج»، «الوحدات المباعة شهريًا»، «المخزون الحالي»، «تكلفة الوحدة»، «سعر البيع». ويمكن إضافة «رمز المنتج»، «الفئة»، و«حد إعادة الطلب». يدعم الموقع أيضًا عدة عناوين إنجليزية شائعة. إذا لم يكن حد إعادة الطلب موجودًا، تُستخدم القيمة صفرًا.

## قواعد التحليل

- قيمة المبيعات الشهرية = الوحدات المباعة شهريًا × سعر البيع.
- الربح الإجمالي الشهري التقديري = الوحدات المباعة شهريًا × (سعر البيع − تكلفة الوحدة).
- قيمة المخزون = المخزون الحالي × تكلفة الوحدة.
- تُصنّف المنتجات إلى: نفد المخزون، إعادة طلب، مخزون منخفض، مخزون مستقر، مخزون زائد، أو بلا مبيعات.
- اقتراح التوريد يستهدف مخزونًا يقارب مبيعات شهرين أو حد إعادة الطلب، أيهما أعلى.

كل النتائج تقريبية وتعتمد على البيانات المدخلة؛ لا تُعد بديلًا عن قرار مسؤول المخزون أو مراجعة تكاليف النقل والموسمية ومدة التوريد.

## المكتبات

- [SheetJS](https://github.com/SheetJS/sheetjs) لقراءة ملفات Excel وCSV في المتصفح.
- [Chart.js](https://www.chartjs.org/) للرسوم البيانية.
